# Prototype Composite Assets

These assets are cropped from the approved May 16 draft sheets for Unity
composition and animation testing.

Use them for:

- sky and far background layers
- bridge midground layer
- code-generated road projection with texture and lane strip
- rear car sprite
- roadside object spawning and scaling
- sign spawning
- weather overlay checks

Do not treat these cropped PNGs as final production slicing. The production
pack still needs transparent sheet cleanup, consistent pivots, import presets,
and final route-pack metadata.
