# NewTrip Unity Scenes

Use the Unity Editor menu to create the road prototype scene:

```text
NewTrip > Road Prototype > Create Or Refresh Scene
```

The generated scene path is:

```text
Assets/NewTrip/Scenes/RoadPrototype.unity
```

The scene intentionally starts from code-generated placeholder assets. Production driving should not use a full-screen driving image.

Side Object guardrail review:

```text
NewTrip > Road Prototype > Create SideObject Guardrail Review Scene
NewTrip > Road Prototype > Capture SideObject Guardrail Review
```

This review scene adds only the first projected roadside asset, `roadside_guardrail_low_wooden_01`, on top of the accepted car/road stack.
