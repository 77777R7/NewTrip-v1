# Triage Labels

Use these canonical triage roles for GitHub Issues.

| Role | Label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate or classify. |
| `needs-info` | `needs-info` | Waiting on missing context or a human answer. |
| `ready-for-agent` | `ready-for-agent` | Fully specified and safe for an agent to implement. |
| `ready-for-human` | `ready-for-human` | Needs human design, product, or review judgment. |
| `wontfix` | `wontfix` | Will not be actioned. |
